Releasing a Skill Change

flow without screens · each state is a code block or a table · onmywatch 0.31.0

A skill change reaches users only after a version bump, a sync, a commit and a push.

  • Commit hooks always run. Fix what they find; never skip them.
  • The agent cannot push to main, so you run the push yourself.
