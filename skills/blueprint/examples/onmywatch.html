How onmywatch Works

Claude Code plugin · v0.17 · github.com/dip497/onmywatch

onmywatch is one plugin. Skills change how the agent answers, designs and recovers.

  • just-tell-me runs in every session. You start the others, or the agent does.
  • Each skill has evals that run with and without the plugin.
  • A change reaches your session only after a version bump and an update.
A

Four folders hold the whole plugin.

repository root
onmywatchone plugin, one marketplace
  • skills/one folder per skill, one SKILL.md in each
  • hooks/starts just-tell-me in every session
  • evals/test cases for each skill
  • .claude-plugin/name, version and marketplace

E

Three steps take an edit to your session.

dashed is a step you run
Edit SKILL.md→Bump version→git push→plugin update→Restart

The installed copy is a cache. Without the three steps, a session keeps the old skill.
