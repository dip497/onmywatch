B

Anatomy of a skill file

skills/brooooo/SKILL.md
name: brooooothe command you type  ·  description: Invoke when the agent goes the wrong way…what the agent matches to start it  ·  disable-model-invocation: trueonly you can start it

The description decides when a skill starts. The name only decides what you type.
